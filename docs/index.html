Simple Design

A native, incremental Sketch-like vector design tool, built in pure Rust with egui/eframe.

Simple Design is a desktop app for building UI mockups and vector artwork: pages full of artboards, shapes, paths, text, and images, with the layer/inspector/canvas workflow familiar from tools like Sketch or Figma. It's a native window (not a web app or webview) — everything from rendering to hit-testing to PNG export is implemented from scratch on top of egui.

What's implemented

Simple Design covers a substantial slice of a "core vector editor" feature set:

  • Pages, artboards, groups, and a recursive layer tree with fill/stroke styling
  • Shape tools — Rectangle (per-corner radius), Oval, Line, Arrow, Star, Polygon, and a freeform vector Pen tool with bezier handles
  • Boolean shape operations (Union / Subtract / Intersect / Difference / Add) as a non-destructive, live-recomputed BooleanGroup
  • Text layers with rich typography — five bundled font families plus any OS-installed font, real bold/italic, alignment, lists, and per-character rich-text formatting
  • Images — insert, crop, magic-wand select, background removal, color adjustment
  • Masking ("use as mask"), alignment/distribution, grids, rotate-copies, flip, flatten
  • Rulers, guides, snapping, and a pixel grid overlay
  • Undo/redo, copy/paste (including cross-instance via the OS clipboard), PNG export

For the full running list of what's done vs. planned, see ROADMAP.md in the repository root.

Project layout

PathWhat lives there
src/model/Pure data model — Document → Page → Layer tree, serialized to .sdesign JSON
src/canvas.rsThe interactive canvas: coordinate transforms, hit-testing, drawing, all drag/click gestures
src/ui/Panels — layers panel, inspector, toolbar, pages bar — each emitting action enums
src/app.rsOwns undo history, selection, current tool; wires panels together each frame
src/export.rsRenders a layer subtree to a PNG via tiny-skia, independent of the canvas renderer
src/history.rsSnapshot-based undo/redo
