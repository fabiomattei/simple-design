Tools & Features

Every tool, menu command, and keyboard shortcut, as a user-facing tour.

Tools

Selected from the toolbar or via a single-letter shortcut (no modifier — plain R, not ⌘R):

ToolKeyWhat it does
SelectVClick, drag, marquee-select, move, and resize layers
PanHDrag to pan the canvas (space-bar-hold also works from Select)
ArtboardADraw a named artboard frame; shapes drawn on top auto-nest into it
RectangleRDrag to draw; independent per-corner radius in the Inspector
OvalODrag to draw an ellipse
LineLDrag between two endpoints; exact direction is preserved on resize
ArrowWLike Line, with configurable start/end cap markers
StarSRegular star; point count and inner radius ratio are adjustable
PolygonGRegular N-gon; side count is adjustable
PenPFreeform vector path — click for corner points, drag for bezier handles
TextTClick for an auto-sizing label, or drag for a fixed-width wrapping box
ScissorsCCut a path at a point, splitting it into open segments

Menus

File

  • New, Open…, Save (⌘S), Save As… (⇧⌘S)
  • Export Selection as PNG… (⌘E) — enabled with exactly one layer selected; renders that layer and its children via the standalone export.rs rasterizer
  • Reduce File Size — resamples every image in the document down to its on-screen pixel size

Insert

Switches to a shape/text tool, or opens a multi-file picker for Image… (placed in an auto-arranged grid if several are chosen at once).

Edit

  • Undo / Redo — ⌘Z / ⇧⌘Z (or ⌘Y)
  • Duplicate (⌘D) / Duplicate Below (⇧⌘D), with a configurable default offset
  • Group (⌘G) / Ungroup (⇧⌘G)
  • Use as Mask (⇧⌘M)
  • Flip Horizontal (⇧H) / Flip Vertical (⇧V)
  • Rotate Copies — duplicates a selection N times around a center, stepping by a given angle
  • Make Grid — duplicates a single layer across a cols × rows grid with configurable gutters
  • Union / Subtract / Intersect / Difference / Add — boolean shape combine (needs 2+ selected layers), plus Flatten to bake any compound shape down to a plain path
  • Convert to Outlines (⌥⌘O) — turns a single Text layer's glyphs into editable vector shapes
  • Rename All… and Rename with Last Format — batch rename with numbering/case rules

View

  • Rulers, Pixel Grid, Snapping — runtime toggles, not saved in the document
  • Clear Guides — removes this page's ruler guides (guides themselves are saved per-page)

Selection & editing shortcuts

⌘ASelect every layer among the current selection's siblings (or the whole page); on a single selected Path, selects every point on it instead
Arrow keysNudge selection 1px (10px with ⇧)

⌘RInline-rename a single selection, or open Rename All for a multi-selection

↵Exit Scale mode, or start in-place editing on a selected Text layer
⌥⌘LToggle aspect-ratio lock while resizing

EscClear selection

Canvas interactions

  • Marquee select — drag on empty canvas; hold ⌥ for "must be fully contained" instead of "overlaps," hold ⌘ to descend into groups/artboards, hold ⇧⌘ to invert against the current selection instead of adding to it
  • Shift-click — toggle a layer into/out of the selection; reaches into groups/artboards directly even without marquee's ⌘ modifier
  • Group move / resize — dragging a multi-selection moves all of it; dragging a handle scales the whole bounding box proportionally
  • Rotate — drag a selected shape's rotation handle; only ever applies to a single leaf shape, never to a Group/Artboard itself
  • Snapping — edges/centers of top-level layers and guides act as snap targets while dragging or resizing
